# Module 1

Introduction to Machine Learning:
Learn what machine learning is, when to use it, and how to structure a machine learning project with the CRISP-DM framework.

In this module, I had:

Compared machine learning systems with rule-based systems.
Learned the foundations of supervised learning.
Used CRISP-DM to organize a machine learning project.
Understood the basic model-selection process.
Seted up the course development environment.
Outcome: a structured approach to framing machine learning problems and starting a reproducible project.
